Privacy

Short, because there's nothing to collect.

Dinky Cal doesn't collect, store, send, or sell any of your data. It has no accounts, no analytics, and no network access at all.

Your calendars

To show which days are busy, Dinky Cal asks macOS for permission to read your calendars. It reads events for the month you're looking at, works out the dots, and shows them to you. That happens entirely on your Mac. Nothing is written to your calendars and nothing leaves your computer.

You can turn calendar access off any time in System Settings → Privacy & Security → Calendars. Dinky Cal keeps working as a plain month calendar.

Your settings

Your preferences (which calendars count, your busy hours, the hotkey) are saved on your Mac in the app's own settings folder, ~/Library/Containers/com.joshtronic.dinkycal. Moving the app to the Trash leaves that folder behind; delete it too to remove everything, or run brew uninstall --cask --zap dinkycal if you installed with Homebrew.

The network

Dinky Cal runs in Apple's app sandbox with only two permissions: the sandbox itself and reading calendars. It has no permission to use the network, so it can't send anything anywhere even if it wanted to. The source code is public on GitHub if you'd like to check.

This website

dinkycal.com is a static page hosted on GitHub Pages. It uses no cookies, analytics, or trackers, and loads nothing from other sites. GitHub may keep standard server logs; see GitHub's privacy statement.
